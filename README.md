# ESC-ImageRegistration
Image Registration Using Extremum Seeking Control (ESC)

This code provides the core implementation of affine image registration using ESC in below paper. 

Yan J, Liu C, Liu H, Huang B, Tang MX, Liu Y, Tan Y. Efficient Image Registration for Ultrasound Localization Microscopy by Obtaining Gradients via Integration Across Iterations. arXiv preprint arXiv:2606.18887. 2026 

Code is published under a Creative Common license for non-commercial use (CC-BY-NC), and therefore can be used for non-commercial, personal or academic use as long as the paper is correctly cited.

Code is developed and tested in MATLAB R2024b on a desktop (CPU: intel core i9-14900k; GPU: NVIDIA GeForce RTX 4070 SUPER; RAM: 128 GB).
